# Finance-Automation-with-python
Simple finance automation with Python — upload, categorize, and visualize transactions.

A simple **personal finance automation app** built with **Python, Streamlit, Pandas, and Plotly**.  
This project helps you upload your bank transactions, categorize expenses, and visualize them with interactive dashboards.

---

## 🚀 Features (Initial Version)
- Upload CSV files of transactions
- Automatically categorize expenses with editable categories
- Track **debits (expenses)** and **credits (income)**
- Interactive **expense summary** with pie charts
- Save categories for future uploads
- Category-wise budgets and overspending alerts ✅ (new add on)
- Monthly/weekly expense trends (new add on)
